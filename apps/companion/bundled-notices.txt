# The third-party notices (and the font they cover) the built companion ships, one per line:
#   <kind> <name in the app> <its source, from the repo root; {platform} is xros or ios>
# Kinds: license (each platform's <platform>/licenses/, the device app's), font (each platform's <platform>/,
# the start screen's face), acknowledgement (Contents/Resources/Acknowledgements/, the About panel's).
# One list read by both sides, so they can't drift: bundle-resources.sh checks its own output against it
# (exactly these files, each byte for byte its source; Acknowledgements/ also has README.txt, which it
# writes, and Sparkle.txt, which the build copies), and AcknowledgementsTests checks the license and font
# names against ClientAssembly.licenseFiles and fontFile, what the companion copies into the device app.

license rust-std.html work/idevice/{platform}/licenses/rust-std.html
license goodmountain.txt work/fonts/LICENSE.md
font Goodmountain-Regular.otf work/fonts/Goodmountain-Regular.otf
